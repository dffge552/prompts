Token 使用說明

為什麼要算 Token？

Llama 3 8B 的上下文窗口只有 8K tokens（輸入 + 輸出總和）。若提示詞太長，模型會強制截斷輸入，導致它看不到你貼的關鍵程式碼。

安全閾值

輸入 tokens狀態
< 6000✅ 安全
6000 – 7000⚠️ 警示
> 7000🚨 危險

減少 Token 的方法

① 只貼目標函式，不貼整個檔案。

② 刪掉程式碼裡所有註解。

③ 編譯錯誤只貼有 error 的行，不貼完整 log。

④ 用第 0-4 類（仿寫代碼）取代「貼大段參考代碼」。

注意事項

此計算器使用 Llama 3 官方 tokenizer 離線計算，所有內容僅在瀏覽器本地處理，不會上傳。
若載入失敗（例如檔案缺失或瀏覽器不支援 ES modules），請確認同一資料夾下有 llama3-tokenizer-with-baked-data.js。
