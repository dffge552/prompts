🐍 Python 考場錯誤百科

考場最常見的 Python 錯誤：語法、縮排、型別、超時、邏輯陷阱。每張卡片都有「錯誤示範」與「正確寫法」。

🔍
📋 複製全部錯誤清單：把所有錯誤整理成一份文字清單，貼給 AI 說「請根據這份清單檢查我的程式碼」。

🛑 語法與縮排（考場直接 0 分的元凶）

縮排 IndentationError：縮排不一致 / 混用 Tab 與空格
❌ 錯誤示範
if x > 0:
    print("正數")
   print("再印一次")   # 縮排 3 空格，與上面 4 空格不一致
💡 為什麼錯
Python 用縮排定義區塊，同一區塊的縮排必須完全一致。混用 Tab 與空格、或空格數不一致，都會拋出 IndentationError。複製貼上程式碼時最容易發生。
✅ 正確寫法
if x > 0:
    print("正數")
    print("再印一次")   # 統一 4 個空格
考場鐵律：全檔案統一用 4 個空格縮排；把編輯器的 Tab 設為自動轉空格。
全形符號 SyntaxError：混入中文全形標點
❌ 錯誤示範
print（"hello"）      # 全形括號
if a > 0，b < 10:      # 全形逗號
    pass
💡 為什麼錯
Python 只接受半角（ASCII）符號。全形括號 （）、逗號 ，、冒號 ： 都會被視為非法字元，拋出 SyntaxError: invalid character。
✅ 正確寫法
print("hello")
if a > 0 and b < 10:
    pass
打程式碼前先切回英文輸入法；複製 AI 的程式碼後，務必檢查標點是否為半角。
語法 SyntaxError：少冒號、少括號、= 與 == 混淆
❌ 錯誤示範
if x > 0          # 少冒號
    print("a"       # 少右括號

if a = 1:         # 把比較寫成賦值
    pass
💡 為什麼錯
if / for / while / def / class 結尾都必須有冒號 :；括號必須成對；比較相等用 ==，= 是賦值。
✅ 正確寫法
if x > 0:
    print("a")

if a == 1:
    pass
型別 TypeError：input() 拿到的是字串，不是數字
❌ 錯誤示範
a = input()
b = a + 1          # TypeError: can only concatenate str to str
💡 為什麼錯
input() 永遠回傳字串（str），即使你輸入的是數字。字串不能直接和整數做算術運算。
✅ 正確寫法
a = int(input())
b = a + 1

# 一行讀多個整數：
x, y = map(int, input().split())

# 讀一整行整數成 list：
nums = list(map(int, input().split()))
考場 考場禁止多餘的 input() 提示與 print()
❌ 錯誤示範
n = int(input("請輸入 n："))   # 提示字串會混進輸出
print("答案是：", ans)            # 多印了題目沒要求的文字
💡 為什麼錯
考場系統透過 stdin 餵資料，input() 的提示字串會出現在 stdout，造成**輸出格式錯誤**；若程式等待互動，還可能**卡住直到超時**。輸出必須與題目要求**一字不差**。
✅ 正確寫法
n = int(input())
print(ans)                     # 只印題目要的答案
正式提交前，把所有除錯用的 print 與 input 提示字串全部刪掉。

⏱️ 考場高頻超時原因（Python 比 C 更容易 TLE）

超時 用 for 迴圈逐個處理大數據
❌ 錯誤示範
result = []
for x in big_list:
    result.append(x ** 2)      # 100 萬次以上就可能超時
💡 為什麼錯
Python 的 for 迴圈有直譯器開銷，每次迭代都比 C 慢很多。資料量大時，同樣的邏輯用內建函式或向量化可以快數十倍。
✅ 正確寫法
# 列表推導式（比 for + append 快約 30%）
result = [x ** 2 for x in big_list]

# 若考場允許 numpy：向量化，快數十倍以上
import numpy as np
result = np.array(big_list) ** 2

# 只是求和：用內建 sum，不要自己寫迴圈
total = sum(big_list)
超時 在迴圈裡反覆做「可以一次做完」的事
❌ 錯誤示範
total = 0
for s in strings:
    total += len(s)            # 可以一次 sum(map(len, strings))

found = False
for x in nums:
    if x > 100:
        found = True         # 可以 any(x > 100 for x in nums)
✅ 正確寫法
total = sum(map(len, strings))
found = any(x > 100 for x in nums)

# 其他常用內建：max、min、all、sorted
把迴圈內「不依賴每次迭代變數」的計算，移到迴圈外或改用內建函式。
超時 用 try/except 處理「預期內」的查找
❌ 錯誤示範
try:
    return d[key]
except KeyError:
    return 0             # 頻繁觸發異常 → 拖慢速度
💡 為什麼錯
異常的拋出與捕獲在 Python 中代價很高。把「key 不存在」這種預期內的日常分支用異常處理，會明顯拖慢速度。
✅ 正確寫法
return d.get(key, 0)      # 不存在就回 0，一行搞定

# 或先判斷：
if key in d:
    return d[key]
return 0

🧠 資料型態與邏輯陷阱

邏輯 用 is 比較「值」
❌ 錯誤示範
if x is 5:              # 小整數可能剛好對，但不可靠
    pass

if s is "hello":        # 幾乎一定錯
    pass
💡 為什麼錯
is 比較的是**記憶體位址**（是否同一個物件），不是值。小整數、短字串可能因快取而剛好相同，但這是實作細節，不可依賴。
✅ 正確寫法
if x == 5:
    pass

if s == "hello":
    pass

# is 只用來判斷 None：
if x is None:
    pass
型別 單元素元組漏了逗號
❌ 錯誤示範
t = (5)        # 這是 int，不是 tuple
print(type(t)) # <class 'int'>
💡 為什麼錯
括號不是元組的關鍵，**逗號**才是。只有一個元素時，必須寫成 (5,)。
✅ 正確寫法
t = (5,)
print(type(t)) # <class 'tuple'>
陷阱 可變預設參數（進階陷阱）
❌ 錯誤示範
def f(lst=[]):
    lst.append(1)
    return lst

print(f())   # [1]
print(f())   # [1, 1] ← 共用同一個 list！
💡 為什麼錯
預設參數只在函式**定義時**求值一次。可變物件（list、dict）會在所有呼叫間共用，導致結果不斷累加。
✅ 正確寫法
def f(lst=None):
    if lst is None:
        lst = []
    lst.append(1)
    return lst
陷阱 淺拷貝 vs 深拷貝
❌ 錯誤示範
a = [1, 2, 3]
b = a
b.append(4)
print(a)        # [1, 2, 3, 4] ← a 也跟著變
💡 為什麼錯
b = a 只是讓 b 指向同一個 list 物件，不是複製。修改 b 等於修改 a。
✅ 正確寫法
# 一維：用 copy()
b = a.copy()
# 或 b = a[:]

# 嵌套結構：用 deepcopy
import copy
b = copy.deepcopy(a)

🔢 浮點數與精確度

浮點 用 == 比較浮點數
❌ 錯誤示範
if 0.1 + 0.2 == 0.3:
    print("相等")    # 不會印！0.1+0.2 = 0.30000000000000004
💡 為什麼錯
二進位浮點無法精確表示 0.1、0.2，0.1 + 0.2 的結果與 0.3 有微小誤差，== 判等失敗。
✅ 正確寫法
if abs(0.1 + 0.2 - 0.3) < 1e-9:
    print("近似相等")

# 金額相關：用整數（分）或 decimal
from decimal import Decimal
price = Decimal("19.99")

📌 其他考場高頻錯誤

索引 IndexError：索引越界
❌ 錯誤示範
a = [1, 2, 3]
print(a[3])          # IndexError：合法索引是 0~2

for i in range(len(a) + 1):
    print(a[i])      # 最後一次 i=3 越界
✅ 正確寫法
a = [1, 2, 3]
print(a[2])          # 最大索引 = len(a) - 1

for i in range(len(a)):
    print(a[i])

# 或直接遍歷元素，避免索引：
for x in a:
    print(x)
字典 KeyError：字典鍵不存在
❌ 錯誤示範
d = {"a": 1}
print(d["b"])        # KeyError: 'b'
✅ 正確寫法
d = {"a": 1}
print(d.get("b", 0))   # 不存在回 0

if "b" in d:
    print(d["b"])
變數 NameError：變數未定義或拼錯
❌ 錯誤示範
counter = 0
print(Counter)       # NameError：大小寫不一致
✅ 正確寫法
counter = 0
print(counter)       # 大小寫一致
數學 ZeroDivisionError：除以零
❌ 錯誤示範
avg = total / count    # count 為 0 時崩潰
✅ 正確寫法
if count == 0:
    avg = 0
else:
    avg = total / count
邊界 range 的邊界搞錯（差一錯誤）
❌ 錯誤示範
for i in range(1, n):    # 只跑到 n-1，漏了 n
    print(i)

for i in range(n + 1):    # 多跑了 n，可能越界
    print(a[i])
✅ 正確寫法
# range(start, stop) 不包含 stop
for i in range(1, n + 1):   # 1 到 n（含）
    print(i)

for i in range(len(a)):     # 0 到 len(a)-1
    print(a[i])
記住：range(a, b) 是 a 到 b-1。
📖 Python 考場生存說明

🚑 遇到錯誤的第一步

看錯誤訊息的**最後一行**，那是錯誤類型與原因；往上看**行號**，那是最後出錯的位置。

常見錯誤類型：SyntaxError（語法）、IndentationError（縮排）、TypeError（型別）、NameError（變數未定義）、IndexError（索引越界）、KeyError（字典鍵不存在）。

🔥 考場三大致命錯誤

  • 縮排不一致
    混用 Tab 與空格，直接 IndentationError。全檔案統一 4 空格。
  • 全形符號
    中文括號、逗號、冒號，直接 SyntaxError。打程式碼前切回英文輸入法。
  • input() 拿到字串
    忘了 int() 轉型，後面算術全部 TypeError。

⏱️ Python 為什麼容易超時

Python 是直譯語言，同樣的迴圈比 C 慢幾十倍。考場防超時優先順序：

  1. 換演算法（跟 C 一樣，先降複雜度）
  2. 用內建函式（sum、max、any、sorted）
  3. 用列表推導式取代 for + append
  4. 用 dict / set 取代線性查找
  5. 考場允許就用 numpy 向量化

🧠 邏輯陷阱速記

  • 比較值用 ==，is 只用在 None。
  • 單元素元組要加逗號：(5,)。
  • 可變預設參數用 None 代替 []。
  • 拷貝 list 用 .copy() 或 copy.deepcopy()。
  • 浮點數比較用 abs(a - b) < 1e-9。
  • range(a, b) 不含 b。
