🤖 ROS 2 rclpy（Python）
用途API / 簽名
初始化rclpy.init(args=args)需搭配 def main(args=None): 使用，以正確解析 ROS 參數。
節點基類class MyNode(Node):（繼承 rclpy.node.Node）
建立發布者self.create_publisher(msg_type, 'topic_name', 10)（10 = 佇列深度）
建立訂閱者self.create_subscription(msg_type, 'topic_name', callback, 10)
建立定時器self.create_timer(period_seconds, callback)
發布訊息publisher.publish(msg)
日誌輸出self.get_logger().info('message')
事件迴圈rclpy.spin(node)
關閉rclpy.shutdown()
銷毀節點node.destroy_node()
訊息類型from std_msgs.msg import Int32；msg = Int32()；msg.data = 42
話題型別全名std_msgs/msg/Int32

⚙️ 環境初始化與版本差異
用途指令 / 說明
確認版本printenv ROS_DISTRO 或 ros2 --version
Source 環境（Humble）source /opt/ros/humble/setup.bash
Source 環境（Jazzy）source /opt/ros/jazzy/setup.bash
工作空間編譯colcon build（兩版通用；Jazzy 對 Python 3.12 的套件依賴更嚴格）
ROS_DOMAIN_IDexport ROS_DOMAIN_ID=10（兩版通用，考場若有多人請確認 assigned ID）
Jazzy 獨有變更 靜態型別參數（static typed parameter）若未提供預設值，會在執行時拋出 ValueError，與 Humble 行為不同。若考題涉及參數宣告，請務必給 default value。
Jazzy 獨有變更 執行器（Executor）重構，改善多節點延遲抖动；rclpy.spin() 預設仍為單線程，但底層排程更穩定。
🧵 POSIX Threads（pthread）
用途簽名 / 說明
標頭檔#include <pthread.h>
編譯gcc -pthread
建立執行緒pthread_create(&tid, NULL, start_routine, arg)；start_routine 型別為 void* (*)(void*)
等待執行緒pthread_join(tid, NULL)
結束執行緒pthread_exit(NULL)
Mutex 靜態初始化pthread_mutex_t mtx = PTHREAD_MUTEX_INITIALIZER;
Mutex 加鎖pthread_mutex_lock(&mtx)
Mutex 解鎖pthread_mutex_unlock(&mtx)
Mutex 銷毀pthread_mutex_destroy(&mtx)
Spinlock 初始化pthread_spin_init(&spin, 0)（0 = 執行緒間共享）
Spinlock 加鎖pthread_spin_lock(&spin)
Spinlock 解鎖pthread_spin_unlock(&spin)
Spinlock 銷毀pthread_spin_destroy(&spin)
📚 C 標準庫關鍵函數
用途簽名 / 格式
記憶體複製void *memcpy(void *dest, const void *src, size_t n)；目標在前，來源在後
記憶體設定void *memset(void *s, int c, size_t n)
固定寬度整數#include <stdint.h>；uint8_t / uint16_t / uint32_t / int32_t
printf 格式符%u（unsigned）、%x（十六進位）、%zu（size_t）、%lu（unsigned long）
🚚 Pico SDK DMA
用途簽名 / 說明
取得空閒通道int chan = dma_claim_unused_channel(true)（true = 沒有通道則 panic）
取得預設配置dma_channel_config c = dma_channel_get_default_config(chan)
設定傳輸大小channel_config_set_transfer_data_size(&c, DMA_SIZE_8)；可選 DMA_SIZE_8 / DMA_SIZE_16 / DMA_SIZE_32
讀位址遞增channel_config_set_read_increment(&c, true)
寫位址遞增channel_config_set_write_increment(&c, true)
配置並啟動dma_channel_configure(chan, &c, dst, src, transfer_count, true)；transfer_count 是筆數，不是位元組數
等待完成dma_channel_wait_for_finish_blocking(chan)
檢查是否忙dma_channel_is_busy(chan)
⚙️ Pico SDK PIO
用途簽名 / 說明
寫入 TX FIFOpio_sm_put_blocking(pio, sm, data)；阻塞直到 FIFO 有空位
從 RX FIFO 讀取pio_sm_get_blocking(pio, sm)；阻塞直到 FIFO 有資料
TX FIFO 是否滿pio_sm_is_tx_fifo_full(pio, sm)回傳 bool，常見用法：while (pio_sm_is_tx_fifo_full(pio, sm)) tight_loop_contents();
RX FIFO 是否空pio_sm_is_rx_fifo_empty(pio, sm)回傳 bool，常見用法：while (pio_sm_is_rx_fifo_empty(pio, sm)) tight_loop_contents();
PIO 實例pio0 或 pio1
狀態機編號sm = 0, 1, 2, 3
